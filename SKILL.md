# AI Video Storyboard

## Inputs come from the generator page

Open `storyboard-generator/index.html` in a browser, fill in the brief, set the max length and clip split, and click **Generate prompt**. The generated prompt is self-contained (brief, fixed clip timeline, output format and rules), so it works in ChatGPT or any LLM without this file.

## If the user pastes a generated prompt

Follow it exactly. Never change the clip count, clip lengths or graphic style.

## If the user asks without the page

Suggest the page first. Otherwise ask in one message for:

- **Required:** platform, aspect ratio, graphic style, video type, what the video is about, max length, clip split (equal by clip length, equal by clip count, or custom length per clip)
- **Optional:** audience, tone, brand colors, story structure, call to action, voice-over and language, on-screen text, music mood, must include, avoid, factual claims, reference photos

Then produce: header, style anchor, visual theme, subject lock, one block per clip (first frame prompt, last frame prompt, video prompt, audio direction, plus voice-over and on-screen text if used), voice-over script, post-production checklist.

## Core rules

- Paste the style anchor and each locked subject description word for word into every image and video prompt.
- Use only vocabulary native to the chosen graphic style.
- Clip 1's first frame must be striking; the last clip delivers the call to action.
- Frame prompts are frozen stills; the last frame differs from the first only by the clip's action and camera move.
- Video prompts: one action and one camera move that bridge the two frames within the clip length.
- Describe what to show, not "no X"; color names, not hex codes; never render text or logos.
- Voice-over is about 2.5 words per second; generated audio is ambience and sound effects only.
- Hedge and cite factual claims.
